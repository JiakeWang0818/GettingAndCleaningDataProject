# Getting and Cleaning Data Course Project
This repository contains the R script and tidy dataset for the course project.

## Files
1. run_analysis.R: R script to clean and transform the raw Samsung accelerometer data.
2. tidy_dataset.txt: Final tidy dataset generated by run_analysis.R
3. CodeBook.md: Description of variables in the tidy dataset.

## How to run the script
1. Download the original UCI HAR Samsung dataset and unzip it into your working directory.
2. Source run_analysis.R in R/RStudio.
3. The script will generate tidy_dataset.txt in your working folder.

The script:
1. Merges training and test datasets.
2. Extracts only mean and standard deviation measurements.
3. Uses descriptive activity names.
4. Labels data with descriptive variable names.
5. Creates a second tidy dataset with average values for each subject and activity.
